 Краткое описание программы
**Цель**: Аппроксимация экспериментальных данных суммой экспоненциальных функций вида:  
y = a₀ + a₁·exp(-x/b₁) + a₂·exp(-x/b₂) + ... + aₙ·exp(-x/bₙ)
 
**Основные функции**:  
- Подбор параметров модели (a₀, aᵢ, bᵢ) для заданного числа экспонент (n).  
- Визуализация результатов (графики, сравнение с исходными данными).  
- Оценка качества аппроксимации через метрики (MSE, MAE, R²).  

**Методы**:  
- **Левенберг-Марквардт**: Градиентный метод для нелинейной оптимизации.  
- **Нелдер-Мид**: Безградиентный метод поиска минимума.  

---



 1. **Решаемая задача**
Программа находит параметры экспоненциальной модели, которая наилучшим образом описывает предоставленные данные. Примеры применений:  
- Анализ кинетики химических реакций.  
- Обработка сигналов с затухающими компонентами.  
- Моделирование физических процессов с экспоненциальным распадом.

---

 2. **Используемые алгоритмы**
```
+----------------------+-------------------------+-------------------------------------------------------------------------------------+
| Метод                | Тип                     | Особенности                                                                         |
+----------------------+-------------------------+-------------------------------------------------------------------------------------+
| Левенберг-Марквардт  | Градиентная оптимизация | Быстрая сходимость, требует вычисления Якобиана, чувствителен к начальным условиям. |
| Нелдер-Мид           | Безградиентный метод    | Работает с симплексом в пространстве параметров, устойчив к шуму, но медленнее.     |
+----------------------+-------------------------+-------------------------------------------------------------------------------------+
```
---

 3. **Архитектура программы**
- **C++ модуль**:  
  - Реализует численные методы оптимизации.  
  - Выполняет тяжелые вычисления (матричные операции, решение СЛАУ).  
- **Python модуль**:  
  - Управляет процессом оптимизации через Bash-скрипт.  
  - Визуализирует данные (Matplotlib/Seaborn).  
  - Считает метрики качества модели.  
- **Bash-скрипт**:  
  - Объединяет C++ и Python части.  
  - Парсит аргументы командной строки и конфиги.  

---

 4. **Ключевые особенности**
- **Гибкость**:  
  - Поддержка любого числа экспонент (n ≥ 1).  
  - Настройка через JSON-конфиг или CLI.  
- **Визуализация**:  
  - Графики в стиле `seaborn`, `ggplot` и других.  
  - Типы графиков: линии, столбцы, точки, комбинированные.  
- **Оценка качества**:  
  - Метрики: MSE (среднеквадратичная ошибка), MAE (средняя абсолютная ошибка), R² (коэффициент детерминации).  
  - Генерация текстовых отчетов.  

---

 5. **Примеры данных**
Входные данные — текстовый файл с двумя столбцами (X и Y):  
```
0.0   5.0
0.1   3.2
0.2   2.1
...   ...
```  
Программа корректно обрабатывает:  
- Данные без явно заданного X (автоматическая нумерация).  
- Данные с неравномерным шагом по X.  

---

 6. **Сценарии использования**
1. **Быстрый анализ через CLI**:  
   ```bash
   ./fit_exponential.sh -f data.txt -n 2 --plot-type all --eval
   ```  
   *Результат: График + отчет в консоли.*

   ```bash

   ```  
   *Результат: Сохраненные PNG-графики и TXT-отчеты.*

3. **Интеграция в научный workflow**:  
   - Экспорт параметров модели в LaTeX-таблицы.  
   - Использование метрик для сравнения моделей.

 Сравнение методов оптимизации
```
+----------------------+-----------------------------+----------------------------+
| Критерий             | Левенберг-Марквардт         | Нелдер-Мид                 |
+----------------------+-----------------------------+----------------------------+
|   Скорость           | Быстрее (для гладких задач) | Медленнее                  |
|   Точность           | Высокая                     | Зависит от параметров      |
|   Устойчивость       | Чувствителен к нач условиям | Устойчив к шуму            |
|   Реализация         | Требует матричных операций  | Проще в кодировании        |
+----------------------+-----------------------------+----------------------------+
```
Программа позволяет выбирать метод в зависимости от характера данных и требуемой точности.```
 Полная инструкция по работе с проектом

---

 1. Python-часть

**За что отвечает**:  
- Визуализация данных  
- Оценка качества модели (MSE, MAE, R²)  
- Управление процессом оптимизации через Bash-скрипт  

**Установка**:  
1. Установите Python 3.8+: [Python Official Site](https://www.python.org/)  
2. Установите зависимости:  
```bash
pip install numpy matplotlib seaborn
```

**Аргументы скрипта `visualize.py`**:  
```bash
python visualize.py \
  [-c CONFIG] \     # Путь к config.json
  [-n NUM] \        # Количество экспонент
  [-f FILE] \       # Файл с данными
  [-m METHOD] \     # Метод оптимизации (nm/lm)
  [--plot-type TYPE] # Тип графика (plot/bar/scatter/all)
  [--save] \        # Сохранить график
  [--eval]          # Вывести метрики
```

**Пример**:  
```bash
python visualize.py -c config.json -n 2 --plot-type all --save --eval
```

---

 2. C++-часть

**За что отвечает**:  
- Реализация алгоритмов оптимизации (Нелдер-Мид, Левенберг-Марквардт)  
- Расчет параметров экспоненциальной модели  

**Требуемые библиотеки**:  
- **Eigen3** (матричные операции):  
  ```bash
  # Ubuntu/Debian
  sudo apt install libeigen3-dev

  # macOS (Homebrew)
  brew install eigen
  ```

**Компиляция**:  
```bash
g++ -std=c++17 -O3 -I/path/to/eigen exponential_fit.cpp -o exponential_fit
```

**Флаги**:  
- `-std=c++17`: Требуемая версия C++  
- `-I/path/to/eigen`: Путь к папке с Eigen (например, `/usr/include/eigen3`)

---

 3. Bash-скрипт (`fit_exponential.sh`)

**Параметры**:  
```bash
./fit_exponential.sh \
  [-c CONFIG] \    # Загрузить конфиг из JSON (default: config.json)
  [-n NUM] \       # Количество экспонент (default: 1)
  [-f FILE] \      # Файл данных (default: data.txt)
  [-m METHOD] \    # Метод оптимизации: nm (default) или lm
  [--plot-type TYPE] # Тип графика (plot/bar/scatter/all)
  [--save] \       # Сохранить график
  [--eval] \       # Включить оценку модели
  [-h|--help]      # Показать справку
```

**Примеры**:  
```bash
 Запуск с конфигом
./fit_exponential.sh -c my_config.json

 Прямое указание параметров
./fit_exponential.sh -f data.txt -n 3 -m lm --plot-type scatter --eval
```

**Справка**:  
```bash
./fit_exponential.sh -h
```

---

 4. Конфигурационный файл (`config.json`)

**Структура**:  
```json
{
  "optimization": {
    "method": "nm",          // Метод: nm (Нелдер-Мид) или lm
    "n_exponents": 2,        // Количество экспонент
    "max_iter": 1000,        // Макс. итераций
    "tolerance": 1e-6        // Точность
  },
  "data": {
    "input_file": "data.txt", // Путь к данным
    "x_column": 0,           // Номер столбца X (с 0)
    "y_column": 1            // Номер столбца Y
  },
  "plot": {
    "type": "plot",          // Тип графика: plot/bar/scatter/all
    "style": "seaborn",      // Стиль: seaborn/ggplot/dark_background
    "title": "Exponential Fit",
    "xlabel": "X",
    "ylabel": "Y",
    "grid": true,            // Сетка
    "save_path": "plot.png", // Путь для сохранения
    "dpi": 300               // Качество изображения
  },
  "evaluation": {
    "metrics": ["mse", "mae", "r2"], // Метрики оценки
    "report_file": "report.txt"       // Файл отчета
  }
}
```

**Правила**:  
- Все пути указываются относительно рабочей директории  
- Для отключения сохранения графика: `"save_path": null`  
- Доступные стили: `print(plt.style.available)` в Python
